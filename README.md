# Garda Handwriting Text OCR

Version: 5.7.31

Turn selected handwritten images and PDF pages into searchable text in Obsidian. Processing is user initiated; review provider data terms before sending sensitive content. Original files remain unchanged unless Replace embed is selected.

## Billing and current offers

The plugin displays the exact current price, product description, availability, and included processed pages returned by the live Constance catalog. Prices and included amounts are not hardcoded in this README or used as a fallback. If the catalog or billing policy is unavailable, purchase controls stay unavailable. Payment is confirmed by the server before account credits are updated.

Usage is measured in processed pages; unchanged cached content may avoid a repeat OCR request.

## Privacy

Only content needed for an operation you start is sent to the service that performs it. Avoid submitting sensitive vault content unless you have reviewed the applicable provider terms. The plugin does not require you to provide a personal AI provider key.

## Installation

Install **Garda Handwriting Text OCR** from Obsidian Community plugins, then enable it in Settings → Community plugins.
See the [user guide](./docs/USER_GUIDE.md) for setup and troubleshooting.
